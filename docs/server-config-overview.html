O que dá pra configurar no servidor

Todo o config.lua, organizado por sistema, com o valor atual e o que cada coisa faz. Serve pra escanear e decidir o que vale mexer — nada aqui foi alterado ainda.

  1. Combate / PvP / mortes
  2. Taxas (XP, skill, loot, regeneração)
  3. Crítico, augments, weapon proficiency
  4. Prey / Task Hunting / Forge / Hazard
  5. Wheel of Destiny / Bestiary / Bosstiary / Boosted
  6. VIP / Loyalty / Livestream
  7. Casas / Mercado / Depot
  8. Mapa / Save do servidor
  9. Conexão / rede / limites
  10. Customs / diversos (autoloot, chain system, etc.)
  11. Performance / dispatcher (avançado)
  12. Banco de dados / status / discord (infraestrutura)

2. Taxas (XP, skill, loot, regeneração)

Vocês já usam data/stages.lua pra XP/skill/magic escalonado — essas configs aqui só valem como fallback (rateUseStages = false hoje, então data/stages.lua é quem manda de fato).

ConfigValor atualO que faz
rateUseStagesfalseSe true, usa as tabelas de data/stages.lua (o que vocês já fizeram); se false, usa os valores fixos abaixo pra TODO o jogo. Confirma que isso não foi mudado por engano, já que vocês investiram tempo no stages.lua.
rateExp / rateSkill / rateMagic1 / 1 / 1Multiplicador fixo de XP/skill/magic — só usado se rateUseStages = false.
rateLoot1Multiplicador de drop de itens dos monstros.
rateSpawn1Multiplicador de velocidade de respawn de monstros.
lowLevelBonusExp50Bônus de % de XP extra pra personagens até level 50 (facilita o início).
rateHealthRegen / rateManaRegen / rateSoulRegen1.0 / 1.0 / 1.0Multiplicador de quanto regenera por tick de vida/mana/soul.
rateHealthRegenSpeed / rateManaRegenSpeed / rateSoulRegenSpeed1.0 / 1.0 / 1.0Multiplicador de com que frequência regenera (velocidade, não quantidade).
rateSpellCooldown1.0Multiplicador de cooldown de magias (menor que 1 = cooldowns mais rápidos).
rateAttackSpeed1.0Velocidade de ataque geral.
rateOfflineTrainingSpeed / rateExerciseTrainingSpeed= rateAttackSpeedVelocidade de treino offline / com exercise weapons.
rateMonsterHealth / rateMonsterAttack / rateMonsterDefense1.0 / 1.0 / 1.0Multiplicadores globais de vida/ataque/defesa de todos os monstros comuns.
rateBossHealth / rateBossAttack / rateBossDefense1.0 / 1.0 / 1.0Mesma coisa, só pra bosses.
rateNpcHealth1.0Multiplicador de vida de NPCs (raramente relevante).
rateKillingInTheNameOfPoints1Multiplicador de pontos da quest "Killing in the Name of".
sortLootByChancefalseSe true, itens raros aparecem primeiro no corpo (evita perder item raro quando o corpo enche com rateLoot alto).

11. Performance / dispatcher (avançado, cuidado)

Essas afetam como o servidor divide trabalho entre threads. Só vale mexer se sentirem lag/travamento com muita gente/monstros — mudar sem necessidade pode causar instabilidade.

ConfigValor atualO que faz
monsterComputeThreads0 (auto)Threads dedicadas a cálculo de IA de monstro. 0 deixa o servidor escolher pelo hardware. Precisa reiniciar pra mudar.
defaultPriority"high"Prioridade do processo no Windows — "high" já dá prioridade boa sobre outros programas.
dispatcherSloMs / dispatcherEmergencyMs50 / 100Limites (em ms) pra quando o servidor entra em modo "correndo atrás" ou "emergência" de sobrecarga.
